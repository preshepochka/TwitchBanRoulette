# TwitchBanRoulette

Рулетка по баллам канала для твоего Twitch-стрима. Зритель тратит баллы на награду, на стриме появляется окно с крутящимися карточками, а бот применяет к нему случайный исход — таймаут, бан, глупое сообщение, VIP или что угодно ещё из того, что ты настроишь.

Всё работает локально на компьютере стримера: ни веб-сервера, ни белого IP, ни хостинга. Окно рулетки захватывается в OBS как любое другое окно.

## Как это работает

1. Ты создаёшь одну награду за баллы канала в панели Twitch (например, «Крутить рулетку — 500 баллов»).
2. Программа следит за активациями этой награды.
3. Когда зритель её активирует, окно крутит ленту карточек, и одна выигрывает — по весам, которые ты задал.
4. Бот выполняет действие этого исхода над зрителем и отмечает активацию исполненной.

Исходы полностью в твоих руках: сколько их, как выглядит каждая карточка, насколько вероятна, что делает и звучит ли она.

## Что нужно

- Python **3.11** или новее (проверено на 3.11–3.13; на 3.14 ставь `pygame-ce` вместо `pygame` — у официального pygame ещё нет сборок под 3.14, см. «Решение проблем»)
- `pip`
- OBS (или любая другая программа захвата окна), если хочешь показывать рулетку на стриме

## Быстрый старт

```bash
git clone https://github.com/preshepochka/TwitchBanRoulette.git
cd TwitchBanRoulette

# создаём и активируем виртуальное окружение
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
```

Теперь попробуй **без всякой настройки и без Twitch-аккаунта**:

```bash

```

Откроется окно, которое само крутится каждые ~5 секунд. **Пробел** — ручной спин. Демо использует картинки-заглушки, звуки и фейкового Twitch-бота — ничего не уходит с твоего компьютера.

Убедился, что работает? Дальше — настройка Twitch.

## Настройка Twitch

От Twitch нужны две вещи: OAuth-токен и ID награды. Сначала зарегистрируй приложение:

1. Открой [Twitch Developer Console](https://dev.twitch.tv/console) → Applications → **Register Your Application**.
2. Name — любое (например, `BanRoulette`).
3. OAuth Redirect URLs — `http://localhost`.
4. Category — `Chat Bot`, Client Type — **Public**.
5. Сохрани **Client ID** — он понадобится для `twitch.client_id`.

### Получение токена

6. Собери ссылку авторизации, подставив свой `YOUR_CLIENT_ID`:

   ```
   https://id.twitch.tv/oauth2/authorize?response_type=token&client_id=YOUR_CLIENT_ID&redirect_uri=http://localhost&scope=channel%3Aread%3Aredemptions%20moderator%3Amanage%3Abanned_users%20chat%3Aread%20chat%3Aedit%20channel%3Amanage%3Apolls%20moderator%3Amanage%3Avips
   ```

   Скоупы `polls` и `vips` нужны только для действий `poll` / `vip_add` / `vip_remove` — но лучше включить их сразу, чтобы потом не переавторизовываться.
7. Открой ссылку, войди как **стример** (владелец канала), нажми *Authorize*. Бросит на `localhost#access_token=...`, страница не загрузится — это нормально.
8. Скопируй токен из адресной строки (кусок между `access_token=` и `&`) в конфиг как `twitch.token`. Префикс `oauth:` не обязателен — срезается автоматически.

### Получение ID награды

Twitch нигде не показывает UUID награды. Достань его скриптом:

1. Создай награду в Creator Dashboard → Viewer Rewards → Channel Points Rewards.
2. Заполни `channel`, `client_id` и `token` в `config.toml`.
3. Запусти:

   ```bash
   python3 scripts/list_rewards.py
   ```

4. Увидишь строки вида `123e4567-...  Моя награда`.
5. Скопируй UUID нужной награды в `twitch.reward_id`.

## Конфигурация

Скопируй `config.example.toml` в `config.toml` и правь под себя. В примере есть все поля с комментариями; минимальная версия выглядит так:

```toml
[twitch]
channel = "your_channel_name"
client_id = "your_client_id"
token = "oauth:your_token_here"
reward_id = "your_reward_id"

[window]
width = 800
height = 200
chroma_key = [0, 255, 0]
overlay = "assets/overlay.png"

[outcomes.Timeout]
image = "assets/cards/timeout.png"
weight = 40
action = { type = "timeout", duration = 60 }

[outcomes.Ban]
image = "assets/cards/ban.png"
weight = 5
action = { type = "ban" }

[outcomes.Nothing]
image = "assets/cards/message.png"
weight = 55
action = { type = "message", text = "{user}, wow, absolutely nothing" }
```

Конфиг валидируется при запуске понятными ошибками с точным указанием ключа — опечатался, и программа говорит, где именно. Неизвестные ключи отвергаются, так что опечатки не проходят молча.

Все пути к файлам — относительно папки, где лежит конфиг.

### `twitch`

Вся секция необязательна — убери её совсем, чтобы тестить локально через `scripts/demo.py`.

| Ключ | Что это |
|---|---|
| `channel` | Имя канала, как в `twitch.tv/<канал>` |
| `client_id` | Client ID зарегистрированного приложения |
| `token` | OAuth-токен из шагов выше |
| `reward_id` | UUID награды, запускающей рулетку |

### `window`

| Ключ | По умолчанию | Что это |
|---|---|---|
| `width`, `height` | — | Размер окна в пикселях |
| `chroma_key` | — | RGB-цвет заливки, он же цвет хромакея в OBS; не должен встречаться в картинках карточек и оверлее |
| `overlay` | нет | Необязательный PNG с альфой поверх всего (рамка, стрелка, лого), размер строго `width × height` |
| `background` | chroma | См. ниже |
| `highlight` | белый, 3 px, радиус 8 | Рамка победителя: `{ enabled, color, thickness, radius }`; `thickness = 0` — залитая; `enabled = false` — выключить |
| `title` | `Twitch Ban Roulette` | Заголовок окна (его ты выбираешь в OBS) |
| `fps` | 60 | Потолок частоты кадров |
| `spin_duration` | 4.0 | Длительность прокрутки, секунды |
| `result_hold` | 3.0 | Сколько подсвечивается победитель, секунды |
| `card_size` | `[200, 150]` | Размер карточки на экране; картинка масштабируется |
| `gap` | 10 | Зазор между карточками, пиксели |

Варианты фона:

```toml
background = { type = "chroma" }                      # сплошная заливка chroma_key — под хромакей в OBS (по умолчанию)
background = { type = "color", color = [20, 20, 30] } # сплошной цвет — захватывай окно напрямую
background = { type = "image", image = "assets/bg.png" }  # картинка на всё окно — захватывай напрямую
```

С фоном `color` или `image` хромакей вообще не нужен: просто захватывай окно в OBS как есть.

### `roulette`

| Ключ | По умолчанию | Что это |
|---|---|---|
| `lead_cards` | `[20, 30]` | Сколько случайных карточек прокрутится до того, как упадёт победитель — увеличь для более долгого спина |

### `sounds`

Вся секция необязательна; без неё приложение молчит. Форматы: **WAV** или **OGG** — MP3 избегай (в SDL_mixer он капризный).

| Ключ | По умолчанию | Что это |
|---|---|---|
| `enabled` | `true` | `false` выключает весь звук, даже настроенный |
| `volume` | 1.0 | Общая громкость, `0.0..1.0` |
| `spin` | нет | Играется лупом всю прокрутку, останавливается на результате |
| `tick` | нет | Клик каждый раз, когда карточка проходит под стрелкой |
| `result` | нет | Играется при раскрытии победителя — если у исхода нет своего звука |

Любой исход может иметь свой звук:

```toml
[outcomes.Timeout]
image = "assets/cards/timeout.png"
weight = 40
sound = "assets/sounds/sting.ogg"   # заменяет sounds.result для этой карточки
sound_volume = 1.0
action = { type = "timeout", duration = 60 }
```

Приоритет при раскрытии победителя: **звук действия** (`type = "sound"`) → **звук исхода `sound`** → **`sounds.result`**.

### `logging`

Вся секция необязательна — по умолчанию лог пишется в консоль на уровне `info`.

| Ключ | По умолчанию | Что это |
|---|---|---|
| `level` | `info` | Детализация: `debug`, `info`, `warning` или `error` |
| `file` | нет | Дополнительно писать лог в этот файл (путь относительно конфига) |

В лог попадает всё полезное: полученные активации, результаты спинов с выпавшим исходом, ошибки действий, опросов и API. Файл дополняется, а не перезаписывается — при долгой работе время от времени подчисти или переименуй его.

```toml
[logging]
level = "info"
file = "roulette.log"
```

### `outcomes`

Каждая секция `[outcomes.Имя]` — один исход: карточка, её вес, необязательный звук и действие.

| Ключ | Что это |
|---|---|
| `image` | Путь к картинке карточки (рекомендую PNG) |
| `weight` | Относительный вес выпадения — не обязан давать 100: `40/5/55` даёт те же шансы, что `4/0.5/5.5` |
| `sound` | Необязательный звук этой карточки, заменяет `sounds.result` |
| `sound_volume` | Громкость этого звука, `0.0..1.0` (по умолчанию 1.0) |
| `action` | Что случится со зрителем — см. ниже |

Действия (инлайн-таблица, валидируется по `type`):

| Действие | Поля | Эффект |
|---|---|---|
| `{ type = "timeout" }` | `duration` (секунды, обязательно) | Таймаут зрителю |
| `{ type = "ban" }` | — | Перманентный бан |
| `{ type = "message" }` | `text` (обязательно) | Сообщение в чат от бота; `{user}` заменяется на имя зрителя |
| `{ type = "nothing" }` | — | Просто показать карточку |
| `{ type = "reroll" }` | — | Крутить ещё раз для того же зрителя; цепочка ограничена 8, потом активация закрывается без эффекта |
| `{ type = "poll" }` | `title`, `choices` (2–5), `duration` (15–300 с), `on_win` (опционально) | Запускает опрос Twitch (нужен скоуп `channel:manage:polls`) |
| `{ type = "vip_add" }` | — | Выдаёт зрителю VIP (нужен `moderator:manage:vips`) |
| `{ type = "vip_remove" }` | — | Снимает VIP (нужен `moderator:manage:vips`) |
| `{ type = "sound" }` | `sound`, `volume` (опционально) | Играет звук и больше ничего не делает — карточка и есть шоу |

Пример исхода «только звук»:

```toml
[outcomes.Airhorn]
image = "assets/cards/airhorn.png"
weight = 5
action = { type = "sound", sound = "assets/sounds/airhorn.wav", volume = 1.0 }
```

### Опросы: пусть чат решает

Опрос может нести последствия — чат голосует, и действие победившего варианта применяется к зрителю, который крутанул рулетку:

```toml
[outcomes.FatePoll]
image = "assets/cards/fate.png"
weight = 10

[outcomes.FatePoll.action]
type = "poll"
title = "Судьба {user}?"
choices = ["Таймаут", "VIP", "Помилование"]
duration = 60

[outcomes.FatePoll.action.on_win]
"Таймаут" = { type = "timeout", duration = 120 }
"VIP" = { type = "vip_add" }
"Помилование" = { type = "nothing" }
```

Как это работает и что помнить:

- Когда опрос заканчивается, бот забирает результат и применяет действие, привязанное к победившему варианту (ключи `on_win` должны совпадать с названиями вариантов один в один; кириллицу в TOML бери в кавычки: `"Баня" = { type = "timeout" }`).
- Действия применяются к **зрителю, запустившему рулетку**, `{user}` в текстах работает как обычно.
- Вариант без маппинга просто ничего не делает.
- Twitch разрешает **только один активный опрос** — если прошлый ещё идёт, новый создать не выйдет: ошибка уйдёт в лог, спин просто покажет карточку.
- Если опрос отменили или результат не прочитался, ошибка попадёт в лог, и ничего не произойдёт; бот какое-то время повторяет попытки, потом сдаётся.
- `reroll` как результат опроса не поддерживается.

## Ассеты: что и как лучше делать

Всё лежит в `assets/`. Заглушки-картинки и звуки уже включены, так что всё работает из коробки — меняй, когда будешь готов. Перегенерировать заглушки можно в любой момент: `python3 scripts/placeholders_generator.py`.

**Карточки** (`assets/cards/*.png`)

- PNG с прозрачностью (RGBA): прозрачные углы выглядят сильно лучше белых квадратов.
- Карточки масштабируются до `card_size` (по умолчанию 200×150 — соотношение 4:3). Рисуй в **том же соотношении сторон**, в идеале **в 2 раза больше** (400×300 или 600×450), чтобы при уменьшании оставалось чётко.
- **Не** используй цвет `chroma_key` в арте карточек.
- Победителя обводит рамка `highlight` — оставь в арте пару пикселей отступа, чтобы рамка ничего не обрезала.

**Оверлей** (`window.overlay`)

- PNG с альфой **ровно** `width × height` (800×200 с дефолтами).
- Всё прозрачное в нём показывает рулетку, всё непрозрачное — перекрывает. Типовое использование: рамка, треугольник-стрелка сверху, лого канала в углу.
- И снова: никакого `chroma_key`-цвета внутри.

**Фон-картинка** (`background = { type = "image", ... }`)

- Она растягивается на окно, так что делай её **точного размера окна** (или того же соотношения сторон), чтобы не искажалась.

**Звуки** (`assets/sounds/*`)

- **WAV** или **OGG**.
- `spin` должен зацикливаться бесшовно: либо трек длиной с `spin_duration` (~4 с), либо чистый лупляемый whoosh.
- `tick` лучше всего работает как очень короткий клик (30–80 мс).
- `result` и звуки исходов: короткий стинг, в идеале короче `result_hold` (~3 с).

**Размер окна**

- Дефолтные **800×200** хорошо работают как баннер под вебкой или геймплеем — в OBS источник позиционируется и масштабируется свободно.
- Хочешь крупнее? Масштабируй `window`, `card_size` и оверлей вместе; `height` держи не меньше высоты карточки плюс небольшой отступ. Для жирной рулетки на пол-экрана хорошо заходит что-то вроде `width = 1200`, `height = 300`, `card_size = [300, 225]`.

## Настройка OBS

С дефолтным хромакей-фоном:

1. Добавь источник **Захват окна**, выбери окно `Twitch Ban Roulette` (это `title` из конфига).
2. На Windows метод захвата — `Windows 10 (1903 and up)`.
3. ПКМ по источнику → Фильтры → **Хромакей**.
4. Тип ключа — `Custom`, цвет — такой же, как `chroma_key` в конфиге (по умолчанию зелёный `[0, 255, 0]`).
5. **Схожесть** подбери на глаз — обычно 400–600.

С фоном `color` или `image` хромакей не нужен вовсе — просто захватывай окно.

**Не сворачивай окно** — убери его под другие окна или на второй монитор. OBS всё равно его захватывает, а свёрнутые окна на некоторых системах перестают отрисовывать кадры.

Звуки играются самим окном, а захват окна **не переносит звук**. Хочешь звук на стриме — добавь системный/десктопный звук отдельным аудиоисточником в OBS.

## Запуск

Настоящий бот (нужна секция `[twitch]`):

```bash
# в активированном venv
python main.py
```

Демо без Twitch — автоматические активации каждые ~5 с, **Пробел** для ручного спина:

```bash
PYTHONPATH=. python3 scripts/demo.py
```

В консоли видно каждую активацию и каждое действие — за решениями бота можно следить вживую. Если с конфигом или ассетами проблемы, программа внятно скажет, что ей не понравилось, и выйдет.

## Решение проблем

**`pygame.error: File is not a Windows BMP file`** при запуске — твоя сборка pygame без поддержки PNG. Случается, когда pip собирает pygame из исходников (обычно на совсем свежих версиях Python). Лечится любым из способов:

```bash
pip uninstall pygame && pip install pygame-ce   # тот же API, есть сборки под новые Python
```

либо используй Python 3.12/3.13 (там есть официальные wheel'ы), либо поставь dev-пакеты (`libsdl2-image-dev`, `libpng-dev`) и переустанови pygame. Проверить диагноз:

```bash
python -c "import pygame.image; print(pygame.image.get_extended(), pygame.image.get_sdl_image_version())"
```

`False` / `None` в выводе — поддержки форматов нет.

**Звуков нет.** Проверь по порядку: секция `[sounds]` есть и указывает на реальные файлы; `enabled` не `false`; файлы в WAV/OGG, а не MP3; и что на машине вообще есть аудиоустройство — без него приложение пишет в лог `audio device unavailable, sounds are disabled` и продолжает молча работать.

**`config is invalid: ...`** — читай сообщение: там точный ключ и что с ним не так (`outcomes.Timeout.action.timeout.duration: Input should be greater than 0`). Сравни с `config.example.toml`.

**Бот не реагирует на активации.** Проверь, что `twitch.reward_id` — UUID той самой награды, что аккаунт токена владеет каналом, и что токен не истёк — при необходимости пройди ссылку авторизации заново.

## Структура проекта

```
main.py             точка входа, собирает всё вместе
app.py              главный цикл: активации → спины → последствия
bot.py              клиент Twitch API и поллинг активаций
outcomes.py         применение действий исходов (timeout/ban/message/...)
roulette.py         выбор победителя, план спина
renderer.py         окно pygame, анимация, звуки спина/тика
audio.py            воспроизведение звука (обёртка над микшером)
config_manager.py   загрузка и валидация config.toml
config_schema.py    схема конфига (pydantic)
assets/             карточки, оверлей, звуки
scripts/            вспомогательные скрипты: demo, список наград, заглушки (не тест-сьют)
```
